01 / INSTALL

Add the Python SDK

From the repository root, install your built wheel in your application's environment.

python -m pip install \
  target/wheels/partly_sdk-*.whl

Requires Python 3.10 or later.

02 / CONNECT

Supply your key

Copy a key from Key Management in this environment. Run these commands, paste your key, and press Enter.

export PARTLY_URL=http://127.0.0.1:8080
read -r -s PARTLY_SDK_KEY
export PARTLY_SDK_KEY
03 / EVALUATE

Make your first check

Create new_checkout in this environment. Copy the example into quickstart.py, then run:

python quickstart.py
